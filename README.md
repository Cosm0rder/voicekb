# ボイス入力 (VoiceKB)

iPhone用の自作音声入力キーボード。キーボードは小さなバーのみで画面を広く使い、
録音と文字起こしは本体アプリ側で行う (iOSの仕様上、キーボード拡張からマイク録音はできないため)。

## 使い方
1. 対象アプリで入力欄をタップし、地球儀キーで「ボイス入力」キーボードに切り替える
2. 「🎤 録音」を押す → 本体アプリが開いて録音開始
3. 話し終わったらマイクをタップ → 文字がクリップボードへ
4. 元のアプリに戻り、キーボードの「貼り付け」を押す → 文章が入る

文字起こしは iOS 標準の Speech フレームワーク (日本語、端末内処理)。サーバー費用なし。
フィラーワード (えーと、あの、等) の簡易除去つき。

## ビルド
GitHub Actions (macOS) で XcodeGen からプロジェクトを生成し、未署名IPAを作る。
IPAは SideStore で自分の Apple ID で署名してインストールする想定。

## 初期設定 (iPhone)
設定 → 一般 → キーボード → キーボード → 新しいキーボードを追加 → ボイス入力
→ 「フルアクセスを許可」をオン (クリップボード読み取りに必要)
